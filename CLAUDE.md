## How to work with me
- **Explain new concepts** the first time they appear, and explain why you chose them, not just what the code does.
  Compare to Python/Java/C++ when that helps.
- **Propose a plan before writing code** for each stage or feature, and wait for my OK.
- Keep changes small enough that I can understand every file before we move on.
- **Tests: I write them myself.** When we get to testing, walk me through each test case
  (what it checks, why it matters, what input and expected result to use), then let me write the test.
  Review my tests afterwards. Don't write the test code for me unless I ask.
- After each stage, I write at least one feature myself and you review it.
